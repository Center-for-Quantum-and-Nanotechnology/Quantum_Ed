# 02 · Quantum Computing Fundamentals

This module builds the foundations you need to understand quantum computation: what a quantum state is, how to describe and picture it, how gates change it, how qubits work together, and how measurement turns a state into an ordinary result. It builds on [01 · Foundations](../01-foundations/index.md), which introduced these ideas in words, and develops their precise meaning.

Every page starts with the core idea, taught through pictures, tables, and interaction. The formal mathematics, such as complex numbers, matrices, and tensor products, comes in at the Intermediate level, so you can choose how far to go.

## Pages

Read them in order. Each builds on the one before.

- **[Quantum States](quantum-states.md)** — what a state is, and how it differs from a measurement result.
- **[Qubit Representation](qubit-representation.md)** — how to write down and calculate with the state of one qubit.
- **[Bloch Sphere](bloch-sphere.md)** — a picture of one qubit's state.
- **[Quantum Gates](quantum-gates.md)** — how ideal gates transform states.
- **[Multi-Qubit Systems](multi-qubit-systems.md)** — what changes when qubits are considered together, including entanglement.
- **[Quantum Circuits](quantum-circuits.md)** — combining qubits and gates into a computation.
- **[Measurement](measurement.md)** — how quantum states produce classical observations.

A single example, preparing and measuring a Bell state, runs through the whole module.
