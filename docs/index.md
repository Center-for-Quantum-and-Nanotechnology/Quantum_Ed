# QuantumEd

**A free, open quantum computing curriculum** for community learners, high school students, and undergraduates.

QuantumEd is built around interactive, visual explanations of core quantum computing concepts — not just text. Each module can be downloaded from the button at the top of the navigation pane so you can keep learning offline.

## How the curriculum is organized

| Module | Focus |
|---|---|
| [01 · Foundations](01-foundations/index.md) | Why quantum computing, what a qubit is, where the field stands today |
| 02 · Quantum Computing Fundamentals | Qubit representation, the Bloch sphere, gates, circuits |
| 03 · Quantum Programming | Python/Jupyter setup, Qiskit and other SDKs, running on simulators and real hardware |
| 04 · Quantum Hardware | Physical qubits, control/readout/noise, hardware modalities |
| 05 · Quantum Software Stack | Compilation, transpilation, runtime, calibration |
| 06 · Quantum Algorithms & Methods | Intro algorithms, VQE, QAOA, quantum annealing |
| 07 · Quantum Error Correction | Stabilizer and surface codes, syndrome decoding, lattice surgery |
| 08 · Labs & Learning Modules | Hands-on labs across programming, hardware, algorithms, and QEC |

## Who this is for

No prior physics or linear algebra background is assumed in Module 01. Later modules build on earlier ones, so the fastest path through is top to bottom — but each module page is self-contained enough to jump to if you already know the basics.
