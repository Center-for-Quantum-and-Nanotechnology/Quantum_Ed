# 01 · Foundations

Start here if you're new to quantum computing. This module builds the vocabulary and mental models everything else in QuantumEd relies on — no linear algebra assumed going in.

## What's in this module

- **[Why Quantum Computing?](why-quantum-computing.md)** — the motivation for the field, the classes of problems it targets, and how it differs from classical computing at a conceptual level.
- **[What Is Quantum Computing?](what-is-quantum-computing.md)** — qubits, superposition, measurement, and entanglement, with an interactive demo.
- **[Quantum Computing Today](quantum-computing-today.md)** — the NISQ era, the path to fault tolerance, and today's practical limitations.

Once you've worked through these three pages, move on to [02 · Quantum Computing Fundamentals](../02-fundamentals/index.md) for the math and circuit model behind the concepts introduced here.
