## Goal

Teach the learner that a quantum state is what a preparation produces, that it is different from what a single measurement returns, and that a superposition is a state, not a bit whose value is merely unknown.

Central progression:

`PREPARE A STATE → MEASURE IT → SEE AN OUTCOME → REPEAT TO SEE A PATTERN → THE PATTERN COMES FROM THE STATE`

Key conceptual transition: **"A state is not what you see. It is what is prepared, and what you see is one outcome drawn from it."**

This page keeps the conceptual story and defers formalism. It builds on Module 01's qualitative demos without repeating them, and ends by asking how a state can be written down so it can be calculated with (02.02).

## Learning outcomes

**Beginner (the Core Learning Contract).** The learner should be able to:

1. Explain what it means to prepare a state, and why the same preparation gives the same state.
2. Name the two basis states, |0⟩ and |1⟩, and say what outcome each one gives when measured.
3. Distinguish a state from a measurement outcome.
4. Predict the pattern of outcomes for a prepared |0⟩, a prepared |1⟩, and a prepared balanced superposition.
5. Explain that a single outcome of a balanced superposition looks random while many outcomes show a pattern.
6. Explain that a superposition is not a classical bit whose value is just unknown, and that measurement counts from one kind of measurement cannot by themselves tell the two apart.
7. Recognize that a state comes with numbers (amplitudes) that decide the probabilities of the outcomes, without calculating with them yet.
8. Recognize that a state can carry something beyond outcome probabilities (phase), which the next pages develop.

**Intermediate (gated).** Explain that two different states can give identical counts for this measurement.

**Advanced (gated).** Name the difference between a pure state and a mixed state.

## Experience-level scope

**Beginner (V1) teaches:** preparation; |0⟩ and |1⟩ as names; superposition as a state; state versus outcome; one shot versus many shots; amplitudes only as "the numbers that decide the probabilities"; phase mentioned as a second ingredient, with no demo.

**Intermediate (future or gated now):** normalization stated precisely; the idea that two preparations with identical outcome statistics can differ in phase (preview only).

**Advanced (future):** pure versus mixed states named and contrasted.

**Not on this page (any level):** vectors, complex numbers, the normalization equation, the Born rule as a formula, measurement formalism, gates, the Bloch sphere. These belong to 02.02, 02.03, 02.04, and 02.07.

Do not build Intermediate or Advanced content merely to make the page fuller.

## Page structure (draft)

1. **From Bits to States.** Reconnect to Module 01's qualitative picture. For a classical bit, what it holds and what you read are the same thing. Ask: "For a qubit, is what it holds the same as what you see?" Set up the page's job: separate the two.

2. **Preparing a State.** A preparation is a recipe. Introduce |0⟩ and |1⟩ as names for the two basis states, and a third recipe that prepares a balanced superposition. Same recipe, same state. A state is a property of the preparation, not of any one measurement.

3. **Main Interactive: "Prepare, Predict, Observe."** The learner chooses a preparation (|0⟩, |1⟩, balanced superposition), predicts what repeated measurements will show, then runs shots and sees the result. See below for the full design.

4. **State vs. Outcome.** Make the distinction explicit with a short comparison: what it is, how you get it, and what one run versus many runs tells you. "A state is what was prepared. An outcome is what one measurement returned."

5. **A Superposition Is Not a Hidden Bit.** Contrast a classical coin hidden under a cup (it is already heads or tails; you just do not know) with a balanced superposition. State plainly that counts from this measurement look the same for both, so counts alone cannot separate them. Name the evidence that does (see open question 2). Do not teach interference or Bell tests here.

6. **The Numbers Behind the Probabilities.** One short block. A state comes with numbers called amplitudes that decide the probabilities of the outcomes. Nothing is calculated here. 02.02 shows how to write and use them.

7. **`[Intermediate]` Same Counts, Different States.** A short gated block: two different states can give identical counts for this measurement, so the counts do not determine the state. No formulas. Previews 02.02 and 02.03.

8. **`[Advanced]` Pure and Mixed States.** A very short gated block naming the difference, with no formalism. Optional; may be cut if the page gets heavy.

9. **From States to Writing Them Down.** Bridge. Ask: "How can we write a state down so we can calculate what it will do?" Next: **Qubit Representation →**

## Main Interactive: "Prepare, Predict, Observe"

- **Controls:** a choice of preparation (|0⟩, |1⟩, balanced superposition); a prediction step; a "measure" action with a shot count (for example 1, 10, 100); "run again"; reset.
- **Predict:** before running, the learner picks what they expect: "always 0," "always 1," or "about half each." After the run, immediate feedback says whether the prediction fit and, for a wrong choice, why that choice does not match the preparation.
- **Observe:** the results appear as counts and bars, using a clear "simulated" label. One shot shows a single result. Many shots show a pattern.
- **Separation:** what the learner changes (the preparation), what the model derives (the description of the state for that preparation), and what is observed (the outcomes) appear in three separate places.
- **State description panel:** a one-line plain-language description of the prepared state ("always gives 0 when measured," "gives 0 or 1 about equally often"). No vectors or numbers beyond that.
- **Accessibility:** keyboard-operable controls, bars paired with text counts, a text summary of each run, and a reset that returns everything to the starting state.
- **Scope fence:** no theoretical-versus-sampled comparison (02.07 owns that), no gates, no Bloch sphere.

### Checks (taxonomy section 7)

- *Prediction task:* inside the interactive (above).
- *Conceptual question:* given short statements, mark each as describing a state or an outcome. Feedback explains each distractor.
- *Transfer task:* a new preparation described as "prepared the same way as the balanced one," asked what a run of 100 shots should look like.

## Important pedagogical constraints (draft)

Do not imply:
- `STATE = OUTCOME`. The state is what was prepared; the outcome is what one measurement returned.
- `SUPERPOSITION = A HIDDEN CLASSICAL BIT`, or its opposite, that these counts prove otherwise. Counts from one kind of measurement cannot tell them apart.
- `SUPERPOSITION = "BOTH 0 AND 1 AT THE SAME TIME" AS A LITERAL PICTURE`, or any single interpretation of quantum mechanics.
- `MEASUREMENT REVEALS A PRE-EXISTING VALUE`.
- That the same preparation gives the same outcome each time. It gives the same state and the same pattern of outcomes.
- That the simulated counts come from real hardware. They are simulated, ideal, and noiseless.

Do not teach here: vectors, complex numbers, the normalization equation, the Born rule as a formula, gates (including H), the Bloch sphere, or measurement formalism.

## End state (draft)

The learner leaves with: `A PREPARATION PRODUCES A STATE → A MEASUREMENT RETURNS ONE OUTCOME → MANY OUTCOMES SHOW A PATTERN → THE PATTERN COMES FROM THE STATE`.

Takeaway: *A quantum state is what a preparation produces. What you see is an outcome drawn from it, and one kind of measurement does not show you the whole state.*

Ends with: "How can we write a state down so we can calculate what it will do?" and **Next: Qubit Representation →**
